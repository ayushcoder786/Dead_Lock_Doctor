# DeadlockDoctor: Course Outcome (CO) Mapping & Academic Evidence

| Course Outcome | Academic Description | DeadlockDoctor Implementation & Concrete Evidence |
| :--- | :--- | :--- |
| **CO-1** | **OS Architecture, System Calls & Shell** | Built-in CLI shell in `src/manager.c` executing external Linux commands via `fork()`, `execvp()`, `waitpid()`. Handles environment variables, `$?` status, GNU Readline history (`~/.deadlockdoctor_history`). System-call tracing module (`src/trace.c`) and comprehensive syscall architectural analysis in `docs/SYSCALL_TRACING.md`. |
| **CO-2** | **Process Creation, Scheduling & Synchronization** | Linux process management demo (`src/process_demo.c`) verifying parent-child relationships, worker task dispatch via `execvp()`, exit codes, and reaping via `waitpid()`. Live process monitor (`src/monitor.c`) tracking process states (READY, RUNNING, BLOCKED, COMPLETED, ABORTED) and high-resolution waiting duration via `CLOCK_MONOTONIC`. |
| **CO-3** | **Inter-Process Communication (IPC)** | Anonymous pipes (`pipe()`), named pipes (`mkfifo()`), and POSIX signals (`sigaction()` with `SIGUSR1`, `SIGALRM`, `SIGTERM`, `SIGINT`) in `src/ipc.c`. Demonstrates message queues, non-blocking descriptors, and signal masks. |
| **CO-4** | **Dynamic Memory, Recovery & Debugging** | Dynamic vector resizing for processes and multi-instance resources. Zero-leak memory architecture validated via GCC AddressSanitizer (`make asan`). Transparent recovery cost calculation: $Cost = (Held \times 2) + (Pending \times 1) + Priority$ with simulated victim abortion in `src/recovery.c`. |
| **CO-5** | **File I/O & File Descriptors** | POSIX buffered line reader (`open()`, `read()`, `write()`, `close()`) in `src/scenario.c`. Persistent append-only event logging in `src/logger.c` (`logs/deadlockdoctor.log`). Event timeline (`src/timeline.c`) recording chronological session events and deterministic step-by-step scenario replay. |
| **CO-6** | **Threads, Synchronization & Deadlocks** | Multi-instance Banker's algorithm (`src/banker.c`), WFG DFS cycle detector and matrix reduction algorithm (`src/detector.c`), resource utilization dashboard (`src/monitor.c`), timeout-based detection with false-alarm auditing (`src/timeout.c`), and POSIX thread synchronization demo (`demo/thread_deadlock.c`) with `pthread_barrier_t`, `pthread_mutex_trylock()`, contention recovery, and Havender lock ordering prevention. |
